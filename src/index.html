⚠ Полный доступ — опасный режим

Переключатель не создаёт песочницу; использовать только если вы осознаёте риск.

Коннекторы и интеграции
Ключи облачных AI-моделей удалены; Localis использует только LamV1.0 локально. Из ключей, относящихся к AI-чату, здесь остаются Telegram bot token и chat ID. У GitHub, Google, Instagram и MCP свои отдельные учётные данные для соответствующих сервисов.

            

            

              
GitHubНе подключён
●

              
              
Ограничьте токен нужными репозиториями и правами. Для чтения нужны Metadata/Contents read; для issues — Issues read/write; для коммитов — Contents read/write.

              

            

            

              
Google WorkspaceНе подключён
G

              
              
              
Создайте OAuth client типа Desktop app в Google Cloud, включите Drive, Docs, Gmail и Calendar API, добавьте свой аккаунт в Test users. Запрашиваются Drive, Gmail и Calendar scopes.

              

            

            

              
Instagram Graph APIНе подключён
◎

              
              
              
Нужен профессиональный Business/Creator аккаунт, связанная Facebook Page и права Meta API. Для публикации: instagram_business_content_publish; личные аккаунты API не поддерживаются.

              

            

            

              
Telegram botНе подключён
➤

              
              
              
Token хранится только в зашифрованном хранилище ОС. Бот должен быть добавлен в чат/канал; в режиме Ask перед отправкой показываются чат и полный текст, а Full access действует согласно общему предупреждению.

              

            

            

              
Arena.ai Agent ModeРучной переход · без сохранения Google-пароля
A

              
Arena.ai Terms запрещают доступ программными и автоматизированными средствами. Поэтому Localis не будет незаметно входить, загружать файлы, отправлять запросы или скачивать результаты с Arena. Открыть Agent Mode можно вручную; публичный интернет Localis читает собственными web-инструментами.

              

            

            

              
Любой MCP Streamable HTTP серверNotion · Slack · Stripe · HubSpot · Hugging Face · Zapier · GitHub MCP и свой
M

              
              
              
              
MCP-сервер получает только вызванные инструменты. В режиме подтверждений каждый tool call отдельно одобряется. OAuth MCP-серверы требуют предварительно завершённой авторизации; здесь задаётся bearer token.

              

            

          


          

            
Plugins
Встроенные навыки применяются в системном контексте; Data Analysis также добавляет реальный локальный анализ CSV/JSON. Импортированный plugin не запускает исполняемый код.

            

            
Интернет-import принимает только небольшие публичные .md/.txt/.json файлы (до 40 КБ), не следует перенаправлениям и требует подтверждения. После загрузки проверьте текст и при необходимости отключите skill.

            

            

          


          

            
Локальные агенты
Команда в чате: install github https://github.com/owner/repository. Localis импортирует только небольшие Markdown-инструкции из корня публичного репозитория; исходный код не клонируется и не запускается.

            

            
Перед сетевым запросом в обычном режиме появится подтверждение. Установка не требует Git for Windows. Проверьте импортированный текст в настройках → Агенты до использования; skills можно выключить или удалить.

            

          


          

            
Общая локальная память
Сводка обновляется после каждого завершённого запроса, общая для чатов и проектов и хранится в отдельном файле на этом компьютере.

            
▤
global-memory.json%APPDATA%\localis-ai\global-memory.json
