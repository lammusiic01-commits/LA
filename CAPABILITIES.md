# Возможности Localis: модель и приложение

Нужно разделять **способности модели Ollama** и **инструменты desktop-приложения вокруг неё**. LLM генерирует текст и, если поддерживает tool calling, предлагает вызовы функций. Файлы, браузер, интеграции, память и команды выполняет Localis. Ни один из этих инструментов не «вшивается» в веса Gemma.

| Возможность | Что делает модель | Что реализует Localis | Что необходимо |
|---|---|---|---|
| Чат и языки | Языковые знания, качество рассуждения, код и context window зависят от выбранной модели | Потоковый Ollama `/api/chat`, выбор установленной модели, настройка языка ответов на русском/английском/латышском | Запущенная Ollama; модель и RAM/VRAM, подходящие компьютеру |
| Планирование и инструменты | Модель формулирует план и native tool calls | До 8 циклов агента и 12 вызовов инструмента за turn; activity sidebar показывает реальные действия | Модель с поддержкой tool calling |
| Интернет | Без доступа к сети знания могут быть устаревшими | DuckDuckGo, извлечение публичного HTML с проверкой URL/redirect, отдельное Chromium-окно | Интернет; поисковый запрос и внешний переход видны пользователю |
| Файлы и приложения | LLM пишет текст/код и предлагает структуру | TXT, Markdown, код, JSON/CSV/YAML; чтение/запись; команды сборки; DOCX/PDF/XLSX/PPTX | По умолчанию рабочая папка; команда требует подтверждения. Полный доступ может выйти за workspace и не является OS-песочницей |
| Данные | Модель интерпретирует результаты | Реальный локальный анализ CSV/TSV/JSON/JSONL: ряды, пропуски, numeric summaries, частые значения | Файл в workspace (или полный режим доступа) |
| Vision | Требуется мультимодальная vision-модель | До 5 изображений во вложениях передаются локальной Ollama | Модель vision и поддержка image input в Ollama |
| Генерация картинок | Текстовая Gemma не является генератором изображения | Отправляет prompt в AUTOMATIC1111/Forge API или ComfyUI и сохраняет PNG в рабочую папку | Установленная image-модель/checkpoint и запущенный локальный сервис |
| Видео | Для text-to-video нужна отдельная специализированная модель | Создаёт MP4/H.264-слайдшоу из кадров через ffmpeg | ffmpeg и готовые кадры; text-to-video не включено |
| GitHub, Google, Instagram | Модель планирует нужный API вызов | Прямые API-инструменты; записи/issues/drafts/events и публикации отделены подтверждением | Свои credentials, scopes и настроенные приложения; API-квоты/тарифы |
| Manus-каталог и другие SaaS | Модель вызывает предоставленные функции | MCP Streamable HTTP для Notion, Slack, Stripe, HubSpot, Hugging Face, Zapier и других доступных серверов | Пользователь настраивает подходящий MCP endpoint и его auth; один каталог не создаёт учётные данные |
| Облачный AI | Не меняет локальную модель | Опциональные API-вызовы OpenAI, DeepSeek, OpenRouter, xAI/Grok для специалиста/fallback | Сохранённый API-ключ; отдельно выбранный провайдер; подтверждение, если полный доступ выключен |
| Plugins и агенты | Исполняет текстовые system/skill-инструкции | Встроенные Data Analysis, Design, Motion, Frontend, QA; импорт локального skill-файла; GitHub импортирует только ограниченные Markdown-инструкции | Пользователь просматривает, включает/отключает навыки. Код репозитория не импортируется и не запускается |
| Общая память | Модель не сохраняется между запусками сама по себе | Ограниченная локальная сводка последних задач + одобренные заметки для будущих чатов и проектов | Профиль приложения Windows; распространённые API-токены маскируются перед записью в сводку |
| Самообучение | Ollama inference не меняет веса модели | Localis хранит контекст и настройки; fine-tuning отсутствует | Для обучения нужна отдельная модель обучения, набор данных и вычислительные ресурсы |

## Режимы разрешений

1. **Ask (по умолчанию):** каждое действие с файлами, командами, внешними коннекторами, MCP и памятью получает отдельную карточку. Пользователь может разрешить или отклонить его.
2. **Full access (явный выбор):** после дополнительного подтверждения отдельные prompts подавляются; доступ выходит за пределы workspace и команды выполняются с правами текущей Windows-учётной записи. Это не изоляция процесса и не средство безопасного запуска произвольного кода. Модель или prompt injection могут ошибиться.

Права этих режимов ограничиваются конкретным процессом Localis, его файловыми путями, включёнными интеграциями и сетевыми API. Localis не может менять системные политики Windows или обходить разрешения ОС.
