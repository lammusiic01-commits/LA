# Возможности Localis: LamV1.0 и desktop-приложение

Localis использует одну встроенную локальную языковую модель — **LamV1.0** (`lam-v1.0`), основанную на Qwen3-4B-Instruct-2507 Q4_K_M в GGUF-формате. llama.cpp выполняет inference через OpenAI-compatible API; C++ launcher определяет доступное оборудование и запускает runtime. Установка из исходников готовится на Windows-сборке, которая включает модель и launcher в installer. Приложение не поддерживает выбор альтернативной локальной модели или локального backend.

Нужно различать генерацию текста моделью и действия desktop-приложения. LamV1.0 предлагает текст и tool calls. Файлы, браузер, коннекторы и память реализованы Localis вокруг модели и **не вшиты в веса**. Локальная память передаёт релевантный сохранённый контекст, но не дообучает веса.

| Возможность | Что делает LamV1.0 | Что реализует Localis | Что необходимо |
|---|---|---|---|
| Чат и языки | Генерирует текст; качество рассуждения, кода и доступная длина контекста ограничены Qwen3-4B Q4_K_M | Streaming OpenAI-compatible `/v1/chat/completions`, fixed alias `lam-v1.0`, настройки языка ответа (русский, английский, латышский) | Встроенные assets и достаточно доступной CPU/RAM/GPU памяти |
| Планирование и инструменты | Формулирует план и предлагает function/tool calls | До 8 agent rounds и 12 вызовов за запрос; потоковый вывод и Activity sidebar показывают реальные шаги | Поддержка function calling шаблоном модели и доступность приложения/движка |
| Интернет | Знания модели сами по себе могут устареть и не являются live-доступом | DuckDuckGo, чтение публичных страниц с проверкой URL/redirect и отдельное Chromium-окно | Интернет; поисковый запрос и внешний переход видны пользователю |
| Файлы и документы | Понимает текст и предлагает содержимое/изменения | TXT, Markdown, код, JSON/CSV/YAML; чтение/запись; команды сборки; DOCX/PDF/XLSX/PPTX | По умолчанию рабочая папка; каждое действие требует подтверждения. Full access не является OS-песочницей |
| Данные | Интерпретирует локальный анализ | Анализ CSV/TSV/JSON/JSONL: строки, пропуски, числовые сводки, частые значения | Файл в workspace или явно выбранный Full access |
| Vision | LamV1.0 в текущем комплекте — текстовая модель | Анализ изображений не заявлен; UI отклоняет image-вложения для чата | Vision для этой сборки не поддерживается |
| Генерация изображений | LamV1.0 формирует текстовый prompt; сама не является image generator | Отправка prompt к AUTOMATIC1111/Forge API или ComfyUI с сохранением результата в рабочую папку | Установленная image-модель/checkpoint и запущенный локальный сервис |
| Видео | LamV1.0 не выполняет text-to-video | Может собрать локальное MP4/H.264-слайдшоу из готовых изображений | ffmpeg и готовые кадры; генерация видео из текста не включена |
| GitHub, Google, Instagram | Модель предлагает вызов подключённого API-инструмента | Прямые API-инструменты для чтения, issue/draft/event и некоторых записей/публикаций | Собственные credentials, scopes, настроенные приложения, API-квоты; запись требует разрешения в обычном режиме |
| Другие SaaS и MCP | Модель вызывает предоставленные функции, если сервер объявил их схему | MCP Streamable HTTP для совместимых сервисов, включая Notion, Slack, Stripe, HubSpot, Hugging Face и Zapier | Пользователь самостоятельно выбирает сервер, endpoint и auth; наличие в каталоге не создаёт credentials |
| Облачный AI | Не меняет локальные веса | Опциональные OpenAI, DeepSeek, OpenRouter и xAI API для specialist/fallback | API-ключ, выбранный провайдер; передача контекста требует разрешения, если Full access отключён |
| Plugins и агенты | Интерпретирует текстовые system/skill-инструкции | Встроенные Data Analysis, Design, Motion, Frontend, QA; импорт локального skill или ограниченных Markdown-инструкций с GitHub | Пользователь просматривает, включает/отключает инструкции. Импортированный код не исполняется |
| Общая память | Не сохраняет опыт в параметрах модели | Локальная краткая сводка последних задач и отдельные заметки для будущих запросов | Профиль Localis; память можно очистить. Fine-tuning не выполняется |
| Производительность UI | Скорость генерации зависит от железа, параметров, контекста и нагрузки | Настраиваемый масштаб; отрисовка следует частоте обновления дисплея | 120 FPS UI возможно только при поддержке дисплея и системы; это не обещание скорости генерации |

## Режимы разрешений

1. **Ask (по умолчанию):** действие с файлами, командами, коннекторами, MCP и памятью сопровождается отдельной карточкой. Пользователь разрешает или отклоняет его.
2. **Full access (явный выбор):** после отдельного предупреждения индивидуальные prompts подавляются; файловый доступ может выходить за workspace, а команды выполняются с правами текущей Windows-учётной записи. Это не изоляция процесса и не безопасный способ выполнять произвольный код.

Разрешения ограничиваются возможностями конкретного процесса Localis, доступностью API и правами Windows. Приложение не может обходить системные политики или права ОС.
