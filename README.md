# Localis — локальный desktop AI-агент

Localis — Windows-приложение с **единственной локальной моделью LamV1.0** (alias `lam-v1.0`). Её базовые веса — Qwen3-4B-Instruct-2507 в формате GGUF Q4_K_M; исходные веса опубликованы под Apache-2.0, а GGUF-сборка фиксируется на конкретной revision и проверяется по SHA-256. C++-launcher определяет доступные CPU/RAM/NVIDIA VRAM параметры и управляет запуском llama.cpp; именно llama.cpp выполняет inference. Launcher не является отдельным inference engine. Модель не содержит весов Claude/Manus, Localis не дообучает её, а сохранение заметок и истории не меняет веса.

Сборочный сценарий Windows подготавливает launcher, llama.cpp runtime и файл модели, проверяет их контрольные суммы и включает всё в ресурсы приложения установщика. **Установленный комплект запускает локальную модель без скачивания её при первом запуске.** Сборка из исходников требует интернета для получения и проверки assets; без подготовленных assets локальный inference недоступен.

Облачные API-ключи языковых моделей и резервные AI-провайдеры удалены. Ответы генерирует LamV1.0; подключённый Telegram bot отправляет сообщения в режиме Ask только после отдельного разрешения. У GitHub, Google Workspace, Instagram и MCP остаются собственные учётные данные, необходимые для прямого доступа к этим сервисам.

## Возможности

- **Меню приложения:** быстрый доступ к новому чату, созданию проекта и папки, рабочей папке, панели активности, подключениям, памяти и настройкам.
- **LamV1.0:** один локальный model alias и backend; потоковый чат и локальные function/tool calls через OpenAI-compatible llama.cpp endpoint.
- **Интернет-исследование:** локальная модель может по ходу запущенного диалога вызывать DuckDuckGo-поиск и чтение публичных страниц; перед сетевыми действиями показываются подтверждения в стандартном режиме. Эти инструменты не работают как запланированный фоновый робот после закрытия приложения.
- **Живая активность агента:** боковая панель показывает шаги, безопасный предпросмотр аргументов, статусы, результаты и ошибки. Ширину боковой панели и панели активности можно менять перетаскиванием; размеры сохраняются локально.
- **Чаты, папки и проекты:** отдельные проектные папки с целью и README. В обычном чате коннекторы выбираются явно; проект использует настроенные подключения и навыки.
- **Файлы и документы:** чтение/запись файлов, запуск команд, анализ CSV/TSV/JSON/JSONL, создание DOCX/PDF/XLSX/PPTX. Доступ регулируется Ask или Full access; последний не является OS-песочницей.
- **Коннекторы:** GitHub, Google Workspace (Drive, Docs, Gmail, Calendar), Instagram Graph API, Telegram Bot API и пользовательские MCP Streamable HTTP servers. Секреты хранятся в защищённом хранилище ОС, не открытым текстом.
- **Arena.ai:** приложение может открыть Agent Mode в системном браузере для ручной работы. Оно не сохраняет пароль Google для Arena и не автоматизирует сайт, не отправляет туда промпты/изображения и не забирает результаты: условия Arena запрещают автоматизированный доступ. Публичные веб-страницы Localis читает собственными web-инструментами.
- **Plugins и GitHub skills:** встроенные Data Analysis, Product Design, Motion Design, Frontend и QA; можно импортировать локальный skill или небольшие Markdown-инструкции из публичного GitHub-репозитория. Код репозитория не клонируется и не исполняется; импортированный текст можно проверить, отключить или удалить.
- **Локальная память:** краткая сводка задач и пользовательские заметки могут подмешиваться в будущие запросы. Это retrieval-контекст, веса модели не меняются.
- **Изображения и видео:** генерация изображений через уже установленный локальный AUTOMATIC1111/Forge или ComfyUI; создание MP4-слайдшоу из готовых кадров через ffmpeg. LamV1.0 не анализирует изображения и не генерирует видео из текста.
- **Адаптивность:** масштаб интерфейса настраивается. Отрисовка следует частоте обновления дисплея; 120 FPS возможно только при соответствующей поддержке дисплея и системы и не относится к скорости генерации.

## Windows 10/11: установка и первый запуск

1. Получите `Localis-Setup-1.2.1.exe` и файл `Localis-Setup-1.2.1.exe.sha256` из артефакта `Localis-Windows` успешного запуска Windows CI. Установщик должен включать приложение, C++ launcher, llama.cpp runtime и модель LamV1.0.
2. До запуска сверьте SHA-256 установщика с sidecar-файлом в PowerShell из каталога с обоими файлами:

   ```powershell
   $expected = (Get-Content .\Localis-Setup-1.2.1.exe.sha256 -Raw).Trim()
   $actual = (Get-FileHash .\Localis-Setup-1.2.1.exe -Algorithm SHA256).Hash.ToLowerInvariant()
   if ($actual -ne $expected) { throw 'Installer SHA-256 mismatch.' }
   ```

3. Запустите установщик и выберите папку. Node.js, Python и отдельная установка модели для работы готового приложения не требуются.
4. Откройте Localis из меню «Пуск» или ярлыка. Приложение запустит LamV1.0 локально и покажет её состояние в верхней панели. Первый запуск может занять время на загрузку модели в память; модель не скачивается в этот момент.

Модель основана на Qwen3-4B-Instruct-2507 Q4_K_M и рассчитана на запуск с автоматическим выбором CPU/GPU-профиля. Производительность и нагрев зависят от драйверов, фоновой нагрузки и доступной памяти.

### Нужно ли удалять старую версию?

**При переходе со старой сборки Localis — да: сначала удалите приложение через Windows → Параметры → Приложения, затем установите новый комплектный installer.** Удаление приложения не должно затрагивать профиль `%APPDATA%\localis-ai`, где находятся настройки, история, память и проекты; не удаляйте эту папку вручную. Последующие обновления, установленные этим Inno Setup installer, используют тот же App ID и ставятся поверх текущей версии.

### Где находятся данные

Настройки, история, заметки, общая память, реестры plugins/агентов и размеры панелей хранятся в `%APPDATA%\localis-ai`. Рабочие документы и проекты — в выбранной папке, по умолчанию `%USERPROFILE%\Documents\Localis Workspace`. Секреты подключений находятся отдельно в `secrets.enc` и шифруются через системное защищённое хранилище Windows. Старые ключи облачных AI-провайдеров из прежних версий удаляются при первом чтении подключений. Защищённое локальное хранение не означает гарантию «навсегда»: удаление профиля, сбой диска или перенос на другой компьютер без резервной копии могут лишить доступа к данным; системное шифрование обычно привязано к профилю Windows.

## Windows: запуск из исходников и сборка

Для разработки нужны Node.js **22.12+**, npm, Windows PowerShell и Visual Studio C++ Build Tools с CMake. Подготовка модели загружает несколько гигабайт проверяемых файлов; для этой стадии требуется интернет и достаточно свободного места. Готовый установленный продукт во время запуска не загружает модель из сети.

```powershell
cd C:\path\to\LA
npm ci
npm test
npm start
```

`npm start` использует заранее подготовленный каталог `release-assets`. Локальная упаковка требует Inno Setup 6.6+ (`ISCC.exe`; в CI используется проверенный Inno Setup 6.7.3). Команда ниже загружает и проверяет pinned assets, компилирует C++ launcher, собирает приложение и упаковывает всё в один Inno Setup installer:

```powershell
npm run dist:win
```

Артефакт появится в `release\Localis-Setup-1.2.1.exe`. Установщик включает runtime и файл LamV1.0; размер единого EXE ограничен возможностями Windows и должен быть меньше 4 ГБ. Требуется несколько гигабайт свободного места и интернет для этапа сборки, не для первого запуска готовой программы. Пользователю готовой сборки Node.js не требуется. Скрипт сборки записывает SHA-256 установщика в `.exe.sha256`; CI smoke-installs EXE, проверяет наличие C++ launcher/runtime/model и сверяет SHA-256 установленной модели с pinned manifest.

## Подключения

### Telegram bot

Создайте бота через официальный `@BotFather`, добавьте его в нужный чат или канал, затем укажите bot token и chat ID в **Настройки → Коннекторы → Telegram**. Localis проверяет token через `getMe`, проверяет выбранный чат через `getChat` и сохраняет token в защищённом хранилище ОС. Отправка сообщения через модель отдельно показывает полный текст и требует разрешения в обычном режиме.

### GitHub

Создайте fine-grained Personal Access Token с минимально нужными правами и ограничьте его нужными репозиториями. В **Настройки → Коннекторы → GitHub** вставьте PAT и нажмите «Проверить и подключить». Доступны список/поиск репозиториев, чтение файлов, issues и запись файла; внешняя запись требует разрешения в обычном режиме.

### Google Workspace

Нужен OAuth Client ID типа **Desktop app** из своего проекта Google Cloud. Включите необходимые Drive, Docs, Gmail и Calendar API и настройте OAuth consent screen. Localis использует ограниченные scopes; Gmail-инструмент создаёт только черновик и не отправляет письмо. OAuth-токены предназначены только для Google Workspace и не применяются для входа на Arena.ai.

### Instagram и MCP

Для Instagram нужны профессиональный Business/Creator аккаунт, связанная Facebook Page, Meta app и Instagram Graph API token. Для MCP в **Настройки → Коннекторы** задайте HTTPS Streamable HTTP endpoint и, если требуется, bearer token; HTTP разрешён только для localhost. Для удалённого сервиса нужны совместимый MCP-сервер и собственная настройка аутентификации.

## Arena.ai и ограничения автоматизации

Кнопка **Arena.ai** открывает страницу Agent Mode в системном браузере. Пользователь входит и работает с сайтом самостоятельно. Localis не управляет браузером, не сохраняет пароль Google для этого сайта, не отправляет от вашего имени промпты/файлы/изображения, не запускает генерацию видео на Arena и не скачивает оттуда результаты. Это ограничение связано с условиями Arena, запрещающими автоматизированный доступ и scraping; без официального разрешённого API скрытая интеграция не реализуется. Localis предоставляет собственные инструменты поиска и чтения публичных страниц; они работают только во время запущенной задачи и при запущенном приложении.

## Разрешения и границы безопасности

- **Спрашивать перед каждым действием** — режим по умолчанию. Для файлов, команд, web-инструментов, внешних сервисов, памяти и MCP Localis показывает действие и ждёт решения пользователя.
- **Полный доступ** включается отдельно и после системного предупреждения подавляет отдельные prompts. Доступ может выходить за workspace; команды выполняются с полномочиями пользователя Windows. Это **не** системная песочница. Ошибка модели или prompt injection может повредить файлы или изменить удалённый аккаунт.
- Web-инструменты разрешают только публичные HTTP/HTTPS адреса и блокируют локальные и частные IP-адреса. Текст веб-страниц и импортированных skills считается недоверенным.
- Генерация изображений требует уже установленной модели и работающего локального A1111/Forge или ComfyUI. Генерация видео из текста не входит в приложение.
- При использовании внешнего сервиса данные передаются только этому выбранному сервису, в пределах соответствующего действия и настроек. Ключи AI-моделей для облачных чат-провайдеров не запрашиваются и не хранятся.
