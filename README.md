# Localis — локальный desktop AI-агент

Localis — desktop-приложение для Windows, которое связывает установленную в Ollama модель (в том числе Gemma с поддержкой tool calling) с локальными инструментами и подключениями. Браузер, плагины, файлы и сервисы реализованы приложением вокруг модели: веса Gemma не меняются, не «дообучаются» и не содержат эти инструменты.

По умолчанию Ollama работает на этом компьютере, файловые операции ограничены рабочей папкой, а перед каждым действием появляется подтверждение. Интернет-сервисы, отдельные облачные AI API и генератор изображений требуют собственной настройки и включаются отдельно.

## Возможности

- **Живая активность агента:** боковая панель показывает план, реальные вызовы инструментов, подтверждения, повторы и ошибки.
- **Чаты, папки и проекты:** отдельные проектные папки с целью и README. У проекта автоматически доступны все сохранённые и подключённые интеграции, API-провайдеры и включённые skills. В обычном чате пользователь выбирает коннекторы и API отдельно.
- **Рабочие инструменты:** веб-поиск и изолированный браузер, чтение и запись файлов, запуск сборки/тестов, анализ CSV/TSV/JSON/JSONL, создание DOCX/PDF/XLSX/PPTX.
- **Коннекторы:** прямые API GitHub, Google Workspace (Drive, Docs, Gmail, Calendar) и Instagram Graph API; каталог также включает Notion, Slack, Stripe, HubSpot, Hugging Face, Zapier и произвольные MCP Streamable HTTP серверы. Для сервисов из каталога, где нет прямого API-клиента, нужен совместимый MCP-сервер.
- **Облачные AI API по выбору:** OpenAI, DeepSeek, OpenRouter и xAI/Grok доступны для специалиста или резервного ответа. Используются только сохранённый ключ и выбранный в обычном чате провайдер; передачу контекста показывает подтверждение, если не включён полный доступ.
- **Plugins и агенты:** встроенные Data Analysis, Product Design, Motion Design, Frontend и QA; импорт навыка из файла или публичного URL на небольшой `.md`/`.txt`/`.json`; команда `install github https://github.com/owner/repository` загружает только Markdown-инструкции из корня публичного репозитория. Код репозитория не скачивается и не исполняется. Импортированный текст можно просмотреть, отключить или удалить.
- **Локальная память:** краткая сводка по последним задачам общая для чатов и проектов, плюс заметки, сохранённые инструментом после подтверждения. Распространённые форматы API-токенов перед сохранением в сводке маскируются. Память не обучает модель.
- **Изображения и видео:** генерация изображения через локальный AUTOMATIC1111/Forge либо ComfyUI; локальное MP4-слайдшоу из кадров через ffmpeg. Text-to-video не встроено.
- **Настройки:** язык ответа агента (русский/английский/латышский), четыре темы, режим разрешений, Ollama, локальный image backend, plugins, API и подключения. Основной интерфейс пока русскоязычный.

## Windows 10/11: запуск приложения

### Требования

1. Установите Ollama с [ollama.com/download](https://ollama.com/download).
2. Скачайте модель, которая поддерживает **tool calling**. Например, если такой тег доступен в вашей версии каталога Ollama:
   ```powershell
   ollama pull gemma4:26b
   ollama list
   ```
   Имя выбирайте точно как в `ollama list`. Перед загрузкой 26B-модели проверьте требования конкретной квантизации к RAM/VRAM; эта модель не подходит каждому компьютеру.
3. Если приложение распространяется как `Localis-Setup-*.exe`, запустите установщик и следуйте шагам мастера. Встроенный NSIS-установщик создаёт ярлык; Node.js и Git конечному пользователю для установленной программы не нужны.

Запустите Localis из меню «Пуск» или ярлыка. Он проверит `http://127.0.0.1:11434` и обнаружит модели Ollama. Если Ollama находится на другом адресе, измените его в **Настройки → Общие → Сервер Ollama**. Настройка удалённого Ollama означает, что переписка будет отправляться на тот сервер.

### Нужно ли удалять старую версию?

**Обычно нет.** Запустите новый установщик поверх прежней версии Localis в ту же папку — при совпадающих `App ID` и каталоге NSIS обновит приложение. Сначала проверьте, что новая версия запускается и видит ваши данные. Если установщик предлагает другой каталог или создаёт отдельную копию, старую можно удалить уже после проверки. Не удаляйте вручную `%APPDATA%\localis-ai`, пока хотите сохранить настройки, историю и память.

### Где находятся данные

Настройки, история, заметки, общая память и реестры plugins/агентов хранятся в `%APPDATA%\localis-ai`. Рабочие документы и проекты — в выбранной рабочей папке, по умолчанию `%USERPROFILE%\Documents\Localis Workspace`. Ключи API и токены подключения находятся отдельно в `secrets.enc`, который Electron шифрует через системное защищённое хранилище Windows (DPAPI). Это постоянное хранение на профиле, а не гарантия «навсегда»: удаление профиля, сбой диска или перенос на другой компьютер без резервной копии могут лишить доступа к данным; DPAPI-секреты обычно привязаны к этому профилю Windows.

## Windows: запуск из исходников и сборка

Требуются Node.js **22.12+** и npm. Git не нужен для импорта GitHub skills, но нужен отдельно, если вы собираетесь работать с исходным Git-репозиторием самого Localis.

```powershell
cd C:\path\to\LA
npm ci
npm test
npm start
```

Собрать NSIS-установщик x64:

```powershell
npm run dist:win
```

Артефакт появится в `release\Localis-Setup-1.1.0.exe`. Переносимая сборка без мастера установки:

```powershell
npm run dist:portable
```

Обе команды собирают Windows x64-приложение. Установленная программа использует Electron и **не требует Node.js у пользователя**.

## Подключения и API

### GitHub

Создайте fine-grained Personal Access Token с минимально нужными правами и ограничьте его конкретными репозиториями. В **Настройки → Коннекторы → GitHub** вставьте PAT и нажмите «Проверить и подключить». Доступны список/поиск репозиториев, чтение файлов, issues и запись файла в репозиторий; внешняя запись всегда требует подтверждения в обычном режиме.

### Google Workspace

Нужен OAuth Client ID типа **Desktop app** из своего проекта Google Cloud. Включите используемые Drive, Docs, Gmail и Calendar API и настройте OAuth consent screen / тестовых пользователей. В Localis выберите **Настройки → Коннекторы → Google Workspace** и войдите через браузер. Используются ограниченные scopes: Drive read-only, Docs, Gmail read-only/compose и Calendar events. Сообщения не отправляются: Gmail-инструмент создаёт только черновик.

### Instagram

Нужны профессиональный Business/Creator аккаунт, связанная Facebook Page, разрешённый Meta app и Instagram Graph API token с нужными правами. Введите token и Instagram User ID. Личные consumer-аккаунты не поддерживаются Graph API; публикация фотографии требует публичного HTTPS JPEG/PNG URL.

### MCP и каталог Manus

В **Настройки → Коннекторы** добавьте HTTPS Streamable HTTP MCP endpoint и, если требуется, bearer token. HTTP разрешён только для localhost. Каждый вызов MCP-инструмента подтверждается отдельно в обычном режиме. Notion, Slack, Stripe, HubSpot, Hugging Face, Zapier и другие сервисы работают через совместимый MCP-сервер, который вы выбираете и настраиваете; их серверные учётные данные не создаются Localis автоматически.

### Внешние AI API

В **Настройки → API** сохраните ключ OpenAI, DeepSeek, OpenRouter или xAI/Grok и укажите модель при необходимости. Проверьте ключ кнопкой «Проверить». Затем:

- в обычном чате включите выбранный API-провайдер переключателем возле поля сообщения;
- для автоматического резервного ответа включите cloud fallback в общих настройках и выберите провайдера. Fallback запрашивается только после сбоя Ollama и, в обычном режиме, отдельного согласия на передачу переписки и контекста.

API-провайдеры не встроены в веса Gemma; за их использование может взиматься плата по тарифу провайдера.

## Разрешения и границы безопасности

- **Спрашивать перед каждым действием** — режим по умолчанию. Для файлов, команд, внешних сервисов, памяти и MCP Localis показывает операцию и ждёт разрешения. Установка GitHub skill отдельно показывает, какие Markdown-файлы будут импортированы.
- **Полный доступ** — отдельный режим с дополнительным системным предупреждением. После включения Localis перестаёт спрашивать для каждого шага и получает доступ к файлам за пределами workspace, командам от имени текущего пользователя и настроенным внешним сервисам. Это **не** системная песочница; ошибка модели или prompt injection может повредить файлы или изменить удалённый аккаунт. Включайте только если доверяете задаче и модели.
- Изолированный браузер не получает Node.js или файловый API приложения; локальные и частные IP-адреса блокируются web-инструментами.
- Публичные веб-страницы, импортированные plugins и GitHub skills являются недоверенным текстом. Их инструкции не дают разрешения запускать код или отправлять секреты.
- Генерация изображения требует уже установленной модели и работающего локального A1111/Forge или ComfyUI. Генерация видео из одного текста не входит в приложение.
- Данные профиля остаются на устройстве, если вы отдельно не выбрали удалённый Ollama, внешний AI API, коннектор или сайт. Вызов внешнего AI отправляет ему выбранный текстовый контекст.
