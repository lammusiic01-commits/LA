# Localis — локальный desktop AI-агент

Localis — Windows-приложение с **единственной локальной моделью LamV1.0** (alias `lam-v1.0`). Её базовые веса — Qwen3-4B-Instruct-2507 в формате GGUF Q4_K_M; исходные веса опубликованы под Apache-2.0, а GGUF-сборка фиксируется на конкретной revision и проверяется по SHA-256. C++-launcher определяет доступные CPU/RAM/NVIDIA VRAM параметры и управляет запуском llama.cpp; именно llama.cpp выполняет inference. Launcher не является отдельным inference engine. Модель не содержит весов Claude/Manus, Localis не дообучает её, а сохранение заметок и истории не меняет веса.

Сборочный сценарий Windows подготавливает launcher, llama.cpp runtime и файл модели, проверяет их контрольные суммы и включает всё в ресурсы приложения установщика. **Установленный комплект запускает локальную модель без скачивания её при первом запуске.** Сборка из исходников требует интернета для получения и проверки assets; без подготовленных assets локальный inference недоступен.

По умолчанию файловые действия ограничены рабочей папкой и требуют подтверждения. Веб-поиск, коннекторы, облачные AI API и генераторы изображений подключаются отдельно и работают только по выбранным настройкам и разрешениям.

## Возможности

- **LamV1.0:** один локальный model alias и backend; русско-, англо- и латышскоязычный интерфейс ответа, потоковый чат, локальные function/tool calls через OpenAI-compatible llama.cpp endpoint.
- **Живая активность агента:** боковая панель показывает реальные вызовы инструментов, разрешения, повторные попытки и ошибки.
- **Чаты, папки и проекты:** отдельные проектные папки с целью и README. В проекте доступны сохранённые и подключённые интеграции и навыки; в обычном чате коннекторы и API выбираются отдельно.
- **Рабочие инструменты:** веб-поиск и изолированный браузер, чтение и запись файлов, запуск сборки и тестов, анализ CSV/TSV/JSON/JSONL, создание DOCX/PDF/XLSX/PPTX.
- **Коннекторы:** прямые API GitHub, Google Workspace (Drive, Docs, Gmail, Calendar) и Instagram Graph API. Для других сервисов доступны настроенные MCP Streamable HTTP серверы; каталог включает Notion, Slack, Stripe, HubSpot, Hugging Face и Zapier.
- **Облачные AI API по выбору:** OpenAI, DeepSeek, OpenRouter и xAI доступны для specialist-вызовов или резервного ответа. Нужны собственный сохранённый ключ и явный выбор провайдера; передача контекста требует отдельного разрешения, если пользователь не включил полный доступ.
- **Plugins и агенты:** встроенные Data Analysis, Product Design, Motion Design, Frontend и QA; можно импортировать локальный skill-файл или Markdown-инструкции из публичного GitHub-репозитория. Код репозитория не клонируется и не исполняется; импортированный текст можно просмотреть, отключить или удалить.
- **Локальная память:** краткая сводка недавних задач общая для чатов и проектов, плюс пользовательские заметки, сохраняемые после разрешения. Память хранится отдельно и не обучает модель.
- **Изображения и видео:** генерация изображений через уже установленный локальный AUTOMATIC1111/Forge или ComfyUI; создание локального MP4-слайдшоу из кадров через ffmpeg. Генерация видео из текста и анализ изображений моделью LamV1.0 не поддерживаются.
- **Адаптивность:** масштаб интерфейса настраивается. Отрисовка следует частоте обновления дисплея; 120 FPS возможно только при соответствующей поддержке дисплея и системы и не относится к скорости генерации.

## Windows 10/11: установка и первый запуск

1. Получите `Localis-Setup-1.2.0.exe`, созданный Windows-сборкой проекта. Установщик включает приложение, C++ launcher, llama.cpp runtime и модель LamV1.0.
2. Запустите установщик и выберите папку. Node.js, Python и отдельная установка модели для работы готового приложения не требуются.
3. Откройте Localis из меню «Пуск» или ярлыка. Приложение запустит LamV1.0 локально и покажет её состояние в верхней панели. Первый запуск может занять время на загрузку модели в память; модель не скачивается в этот момент.

Модель основана на Qwen3-4B-Instruct-2507 Q4_K_M и рассчитана на запуск с автоматическим выбором CPU/GPU-профиля. Профиль с полным offload выбирается при наличии NVIDIA VRAM от 6 ГБ; при меньшей доступной VRAM launcher использует частичный offload или CPU. Система с RTX 5060 8 ГБ, i5-12400F и 16 ГБ RAM соответствует целевому профилю, но производительность и нагрев зависят от драйверов, фоновой нагрузки и реальной доступной памяти.

### Нужно ли удалять старую версию?

**При переходе со старой сборки Localis — да: сначала удалите приложение через Windows → Параметры → Приложения, затем установите новый комплектный installer.** Удаление приложения не должно затрагивать профиль `%APPDATA%\localis-ai`, где находятся настройки, история, память и проекты; не удаляйте эту папку вручную. Последующие обновления, установленные этим Inno Setup installer, используют тот же App ID и ставятся поверх текущей версии.

### Где находятся данные

Настройки, история, заметки, общая память и реестры plugins/агентов хранятся в `%APPDATA%\localis-ai`. Рабочие документы и проекты — в выбранной папке, по умолчанию `%USERPROFILE%\Documents\Localis Workspace`. API-ключи и токены подключения находятся отдельно в `secrets.enc` и шифруются через системное защищённое хранилище Windows. Это постоянное локальное хранение, но не гарантия «навсегда»: удаление профиля, сбой диска или перенос на другой компьютер без резервной копии могут лишить доступа к данным; системное шифрование обычно привязано к профилю Windows.

## Windows: запуск из исходников и сборка

Для разработки нужны Node.js **22.12+**, npm, Windows PowerShell и Visual Studio C++ Build Tools с CMake. Подготовка модели загружает несколько гигабайт проверяемых файлов; для этой стадии требуется интернет и достаточно свободного места. Готовый установленный продукт во время запуска не загружает модель из сети.

```powershell
cd C:\path\to\LA
npm ci
npm test
npm start
```

`npm start` использует заранее подготовленный каталог `release-assets`. Локальная упаковка требует Inno Setup 6.6+ (`ISCC.exe`; в CI используется проверенный Inno Setup 6.7.3). Команда ниже загружает и проверяет pinned assets, компилирует C++ launcher, собирает приложение и упаковывает всё в один Inno Setup installer:

```powershell
npm run dist:win
```

Артефакт появится в `release\Localis-Setup-1.2.0.exe`. В установщик входят runtime и файл LamV1.0; размер единого EXE ограничен возможностями Windows и должен быть меньше 4 ГБ. Требуется несколько гигабайт свободного места и интернет для этапа сборки, не для первого запуска готовой программы. Пользователю готовой сборки Node.js не требуется. До публичного распространения Windows installer и runtime должны пройти Windows CI/build и проверку комплектности модели в собранном приложении.

## Подключения и API

### GitHub

Создайте fine-grained Personal Access Token с минимально нужными правами и ограничьте его нужными репозиториями. В **Настройки → Коннекторы → GitHub** вставьте PAT и нажмите «Проверить и подключить». Доступны список/поиск репозиториев, чтение файлов, issues и запись файла; внешняя запись требует разрешения в обычном режиме.

### Google Workspace

Нужен OAuth Client ID типа **Desktop app** из своего проекта Google Cloud. Включите необходимые Drive, Docs, Gmail и Calendar API и настройте OAuth consent screen. Localis использует ограниченные scopes; Gmail-инструмент создаёт только черновик и не отправляет письмо.

### Instagram

Нужны профессиональный Business/Creator аккаунт, связанная Facebook Page, Meta app и Instagram Graph API token с нужными правами. Требуются token и Instagram User ID. Личные consumer-аккаунты Graph API не поддерживает; публикация фотографии требует публичного HTTPS JPEG/PNG URL.

### MCP и сторонние сервисы

В **Настройки → Коннекторы** добавьте HTTPS Streamable HTTP MCP endpoint и, если требуется, bearer token. HTTP разрешён только для localhost. Каждый вызов MCP-инструмента требует разрешения в обычном режиме. Для сервиса нужен совместимый MCP-сервер и собственная настройка аутентификации; запись сервиса в каталоге не создаёт учётные данные автоматически.

### Внешние AI API

В **Настройки → API** сохраните ключ OpenAI, DeepSeek, OpenRouter или xAI и укажите модель при необходимости. После проверки ключа выберите provider для specialist-вызовов или включите резервный ответ в общих настройках. При резервном ответе после сбоя LamV1.0 Localis просит отдельное разрешение на отправку выбранной переписки и контекста, если не активирован полный доступ. Внешние API не являются локальными backend-ами и могут тарифицироваться провайдерами.

## Разрешения и границы безопасности

- **Спрашивать перед каждым действием** — режим по умолчанию. Для файлов, команд, внешних сервисов, памяти и MCP Localis показывает операцию и ждёт решения пользователя.
- **Полный доступ** включается отдельно и после системного предупреждения подавляет отдельные prompts. Доступ может выходить за workspace; команды выполняются с полномочиями пользователя Windows. Это **не** системная песочница. Ошибка модели или prompt injection может повредить файлы или изменить удалённый аккаунт.
- Изолированный браузер не получает Node.js или файловый API приложения; web-инструменты блокируют локальные и частные IP-адреса.
- Публичные веб-страницы, импортированные plugins и GitHub skills являются недоверенным текстом. Их инструкции не разрешают запускать код или отправлять секреты.
- Генерация изображений требует уже установленной модели и работающего локального A1111/Forge или ComfyUI. Генерация видео из текста не входит в приложение.
- Данные профиля остаются на устройстве, если пользователь отдельно не выбрал внешний AI API, коннектор или сайт. При таких вызовах выбранный контекст передаётся соответствующему сервису.
