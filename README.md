# Localis — локальный desktop AI-агент

**Localis** — настольное приложение для Windows, которое подключает уже установленную модель Ollama к локальным инструментам. Оно не переписывает веса модели и не требует облачного аккаунта: код приложения — это безопасный мост между Ollama, браузером и выделенной рабочей папкой.

Интерфейс, история чатов, память, файлы проектов и основные запросы к модели остаются на этом компьютере. Каждый вызов инструмента перед выполнением показывает отдельный экран подтверждения.

## Что уже умеет

| Возможность | Как работает | Что потребуется |
|---|---|---|
| Локальный чат | Потоковый Ollama `/api/chat`, выбор любой установленной модели | Ollama и выбранная модель |
| Инструменты агента | Поиск, чтение страницы, файлы, документы, команды и медиа через tool calling | Модель должна поддерживать вызовы инструментов; приложение всегда просит подтверждение |
| Интернет и браузер | Поиск DuckDuckGo, извлечение текста публичных страниц, отдельное изолированное окно браузера | Интернет; поисковая строка/адрес отправляются сайту только после подтверждения |
| Анализ изображений | Изображения JPEG, PNG, WEBP, GIF, BMP передаются локальному Ollama | Модель с поддержкой vision, например установленная vision-модель |
| Создание файлов | Текст, код, HTML/CSS/JS/Python/PowerShell/JSON/CSV и другие UTF-8-файлы; DOCX, PDF, XLSX, PPTX | Встроено; сохраняет только в выбранную рабочую папку |
| Создание изображений | Генерация через локальный AUTOMATIC1111/Forge API или ComfyUI API | Скачанная модель для SD/SDXL/Flux и запущенный локальный генератор |
| Создание видео | Сборка MP4-слайдшоу из кадров с сохранением пропорций | ffmpeg; генерация кадров — через локальный image backend |
| Создание приложений | Запись проекта и запуск сборки/тестов в рабочей папке | Node/Python/другие нужные инструменты; каждый запуск команды надо одобрить |
| Локальная память | Одобренные пользователем заметки добавляются в контекст будущих диалогов | Не обучает и не меняет веса модели |

## Быстрый запуск на Windows 10/11

### 1. Установите Ollama и модель

Установите Ollama с [ollama.com/download](https://ollama.com/download), затем в PowerShell проверьте модели:

```powershell
ollama list
```

Если `gemma4:26b` ещё не скачана и такой тег доступен в вашей версии каталога Ollama:

```powershell
ollama pull gemma4:26b
```

Название тега берите именно из `ollama list`: если у вас другая версия/квантизация Gemma, выберите её в списке моделей Localis. Сначала убедитесь, что модель запускается командой `ollama run <точное-имя-модели>`. Для 26B заранее проверьте свободную память/VRAM и требования конкретной квантизации.

### 2. Запустите приложение из исходников

Для запуска из исходников нужен Node.js 22.12 или новее (с npm). В папке проекта:

```powershell
npm install
npm start
```

При первом запуске Localis проверит `http://127.0.0.1:11434`, подхватит модели из Ollama и предложит рабочую папку `Документы\Localis Workspace`. Если Ollama работает на другом адресе, измените его в ⚙ **Настройки**.

### 3. Соберите установщик Windows

```powershell
npm run dist:win
```

Готовый NSIS-установщик появится в `release\Localis-Setup-1.0.0.exe`. Для переносимой сборки без установщика:

```powershell
npm run dist:portable
```

Проверка проекта:

```powershell
npm test
```

Подробная матрица, где заканчиваются возможности модели и начинаются возможности локального приложения, находится в [CAPABILITIES.md](CAPABILITIES.md); схема компонентов — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Как пользоваться

1. Откройте новый диалог и выберите модель Ollama в верхней панели.
2. Опишите задачу обычным языком. Для сайта, программы или документа попросите сначала составить план, а затем записать результат в рабочую папку.
3. Перед внешним запросом, чтением/записью файлов, запуском команд, генерацией медиа или сохранением памяти появится карточка: **проверьте адрес, путь, содержимое или команду и нажмите «Разрешить один раз» либо «Отклонить»**.
4. Созданные результаты доступны через карточку **Рабочая папка** слева.

Поддерживаются вложения изображений и текстовых файлов до 12 МБ; для текстовых вложений в запрос попадает не более 1 МБ. Для vision обязательно нужна модель, которая понимает изображения.

## Изображения и видео

**AUTOMATIC1111 / Forge:** включите API-параметр `--api`, запустите сервер на `http://127.0.0.1:7860`, выберите этот backend в настройках Localis.

**ComfyUI:** запустите ComfyUI на `http://127.0.0.1:8188` и выберите ComfyUI API. Localis отправляет минимальный workflow: checkpoint → prompt → sampler → PNG. Нужна совместимая модель checkpoint в ComfyUI.

**Видео:** поставьте ffmpeg и добавьте его в `PATH`. Попросите Localis собрать MP4 из кадров в рабочей папке. Приложение делает локальное слайдшоу с масштабированием/полями и кодированием H.264. Генерация произвольного видео из одного текста — отдельная возможность специализированной локальной видеомодели, в этот MVP не встроена.

## Безопасность и границы возможностей

- Localis **не вшивает браузер или языки в ядро Gemma**. Веса — это файлы параметров модели; инструменты реализуются приложением поверх Ollama API. Это позволяет менять модели без переобучения и не портить исходную модель.
- Модель не развивается и не дообучается сама. История диалога и подтверждённые заметки памяти дают контекст; это не изменение параметров/весов.
- Локальные модели различаются по качеству русского языка, vision, актуальным знаниям и поддержке tool calling. Если модель не вызывает инструменты, выберите модель с поддержкой tool calling или попросите сформировать файлы обычным текстом.
- Запуск shell-команд требует отдельного подтверждения, но команда исполняется с правами вашей учётной записи Windows и **не находится в полноценной системной песочнице**. Проверяйте её перед разрешением. Не разрешайте неизвестные команды и скрипты из недоверенных сайтов.
- Веб-страницы читаются как извлечённый текст; сайты с авторизацией, CAPTCHA или тяжёлым JavaScript могут не отдать содержимое поисковому инструменту. Для ручного просмотра есть отдельное окно браузера без Node.js-доступа к компьютеру.
- Изображения генерирует настроенная локальная модель, а не Gemma. Качество и скорость зависят от GPU/VRAM, модели и конфигурации.
- Localis не копирует закрытый код ChatGPT, Claude или Manus. Используются публичные протоколы Ollama и стандартные desktop/web API; поведение конкретной модели определяется её лицензией и параметрами.

## Где хранятся данные

- Настройки, история диалогов и память: каталог профиля приложения Electron (в Windows внутри `%APPDATA%`).
- Файлы агента: выбранная рабочая папка.
- Отдельной телеметрии, облачного аккаунта или API-ключа нет. Интернет используется только по явно подтверждённому действию.

## Структура

```text
src/
  main.js              Electron main process, Ollama, approvals, isolated browser
  preload.js           узкий безопасный IPC-мост
  browser-preload.js   IPC-мост окна браузера
  renderer.js          интерфейс, диалоги и consent flow
  lib/agent.js          потоковый tool-calling цикл Ollama
  lib/tools.js          проверка, подтверждение и исполнение инструментов
  lib/security.js       ограничения URL, IP и путей
  lib/web.js            публичный поиск и извлечение страниц
  lib/files.js          workspace I/O и защита от выхода через symlink
  lib/documents.js      DOCX/PDF/XLSX/PPTX
  lib/media.js          AUTOMATIC1111/ComfyUI и ffmpeg
```
